# Interactive Quiz Game

An interactive general knowledge quiz game built using HTML, CSS, and JavaScript. The game features 10 questions about animals, nature, and interesting facts.

## Features

- 10 general knowledge questions
- Four multiple-choice answers for each question
- Randomized question order
- Instant visual feedback for correct and incorrect answers
- Simple and user-friendly interface
- Runs directly in a web browser

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Click Start to begin the quiz.

## How to Play

1. Click Start.
2. Read the question and select an answer.
3. Check the visual feedback.
4. Click Next to continue.

## Project Structure

- index.html - Main webpage
- styles.css - Styling and layout
- script.js - Quiz functionality
- README.md - Project documentation
